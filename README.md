# CRUD Mundo

Projeto simples para prática de criação de API em PHP e frontend em React, com um banco de dados único.

## Tecnologias usadas

- PHP (API)
- React (Frontend)
- MySQL (Banco de dados)
- HTML & CSS

## Como usar

1. Configure o servidor PHP e o banco MySQL.  
2. Coloque o backend na pasta do servidor local.  
3. Rode o frontend com:

    ```bash
    npm install
    npm start
    ```

4. Acesse `http://localhost:3000` no navegador.
